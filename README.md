# WinIsland — «остров» как в iOS для Windows

Чёрная пилюля вверху экрана. Когда есть музыка — в ней обложка, мини-кнопки ▶/⏸ и ⏮ ⏭ и волна.
Показывает и управляет музыкой из YouTube (любой браузер),
Telegram Desktop, Spotify, Яндекс Музыки — всего, что видно в системной плашке громкости Windows.

## Установка
`dist\WinIsland-Setup.exe` — двойной клик → «Установить».

- Ставится для текущего пользователя, права администратора не нужны (папка `%LOCALAPPDATA%\Programs\WinIsland`).
- Создаёт ярлык в меню «Пуск» и (по желанию) на рабочем столе.
- Если нет .NET 10 Desktop Runtime — сам скачает его с сайта Microsoft и поставит (Windows спросит подтверждение).
- В конце предлагает **запускать WinIsland вместе с Windows** и сразу открыть его.
- Повторный запуск установщика обновляет программу и сохраняет прежние настройки.
- Удаление: «Параметры → Приложения → WinIsland → Удалить» (убирает файлы, ярлыки, автозапуск и настройки).

Без установки: `publish\WinIsland.exe` — двойной клик. Иконка появится в трее.

## Как пользоваться
| Действие | Что происходит |
|---|---|
| Обычно | остров спрятан вверху (видна тонкая полоска) — вкладки браузера видно и можно нажимать |
| Наведи мышь на полоску | остров выезжает вниз с «пружинкой» |
| Задержал курсор на острове ~2 с | сам раскрывается большой виджет |
| Увёл мышь | остров снова прячется |
| Мини-кнопки ⏪ ⏯ ⏩ в пилюле | управление музыкой без раскрытия |
| Клик по острову (или по иконке в трее) | раскрывается: обложка, трек, перемотка, ⏮ ⏯ ⏭, яркость, громкость, Wi-Fi, Bluetooth, без звука, скриншот |
| Увести мышь | сворачивается обратно |
| Колесо мыши над островом | громкость (с HUD) |
| Клавиши громкости | остров показывает HUD громкости |
| Новый трек | всплывает баннер «Сейчас играет» на 3 секунды |
| Правый клик по иконке в трее | меню: автозапуск, спрятать, **тёмная / светлая тема**, выход |

Игры и видео на весь экран — остров сам прячется и не мешает.

## Ограничения
- **Яркость** работает на ноутбуках и мониторах с DDC/CI. Если не поддерживается — слайдер тусклый, клик открывает настройки экрана.
- **Режим «в самолёте»** — у Windows нет API для переключения, кнопка открывает настройки.
- Для YouTube подписью будет браузер (например «Google Chrome») — Windows сообщает источник именно так.

## Тема
Правый клик по иконке в трее → «Тёмная тема» или «Светлая тема». Цвета плавно перетекают, остров на пару секунд выезжает, чтобы было видно результат.
Выбор запоминается (`HKCU\Software\WinIsland`, значение `Theme`).

## Пересборка
Установщик (сам соберёт приложение и вшьёт его внутрь): `build-installer.cmd` → `dist\WinIsland-Setup.exe`.
Версия берётся из `<Version>` в `WinIsland.csproj`.

Только программа:
```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```
Проверка дизайна без экрана: `WinIsland.exe --snapshot <папка>` — сохранит PNG всех состояний.
Ошибки (если будут): `%LOCALAPPDATA%\WinIsland\error.log`.
